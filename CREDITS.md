## Based on

- **gta6-save-editor** by CoreyLyu76, GPL-3.0 (https://github.com/CoreyLyu76/gta6-save-editor).
  Save Garage started from its version 0.2.0: the local service, the money editor (`engine/money.py`) and the
  GarlicSaves client (`engine/garlic.py`).
- **GarlicTransfer** by earthonion, GPL-3.0 (https://github.com/earthonion/GarlicTransfer).
  The PS5 Data Transfer code in `vendor/poc` comes from its version 0.3.7. See [vendor/README.md](vendor/README.md)
  for the changes. The GarlicSaves sign-in (`Garlic.sign_in` in `engine/garlic.py`) is adapted from the device
  authorisation flow of its version 0.4.0 (`electron/device_auth.cjs`): the same two requests and the same pace,
  rewritten in Python, with stricter checks of every field GarlicSaves answers, the code's own expiry, a slower pace when
  GarlicSaves asks for one, and its own installation name ("Save Garage").

## Changes in Save Garage

Modified from the projects above, November 2026:

- New ammo and stats editing (`engine/savedit.py`, `engine/statnames.py`) and the matching API.
- New web interface and artwork (`ui/`, `assets/`, `tools/`).
- Optional access from other devices on the home network, with a client allow-list.
- Signing in to GarlicSaves with your own account (1.30.0), adapted from GarlicTransfer 0.4.0's device authorisation,
  in place of the shared worker key GarlicSaves has revoked.
- Renamed and rebranded; new default port 7283; comments translated to English.
- Sending back to consoles that ask for the newer console information and IPv6 data (1.31.0, GitHub issue #7),
  ported by HelloMoon-1 (pull request #10) from ImNotTom's findings on a PS5 Pro, and the help that names the
  network adapter when it has no IPv6 address (1.31.1, pull request #14), and the Windows adapter lookup without psutil
  with the launchers adding missing packages (1.31.2, pull request #18), both also by HelloMoon-1.
- Setting the strength, cardio and focus levels in both places the game keeps them (1.32.0), from ShujiJaeger's
  finding that the game reads them from ScriptCharacterPhysique (HelloMoon-1/save-garage issue #4).
- The four capacity bars: writing both attribute copies and the stats' points and rank together, and checking on a PS5
  that 100 stays after the game saves, from ShujiJaeger.

## Services and assets

- **GarlicSaves** (https://garlicsaves.com) decrypts and re-encrypts saves and derives Data Transfer keys. Save
  Garage signs in to it with your own GarlicSaves account and sends the worker key GarlicSaves gives that sign-in.
- **Anton** font by The Anton Project Authors, SIL Open Font License 1.1 (`ui/fonts/OFL.txt`).
- **psutil** by Giampaolo Rodola, BSD 3-Clause License (its licence is in the package): finds the IPv6 address of the
  network adapter a PS5 uses when it asks for IPv6 data.
- All artwork is original and generated by `tools/make_art.py`. It contains no game assets.
